# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Ways to Contribute

- **Report bugs:** Open an issue describing what happened, what you expected, and the steps to reproduce it.
- **Fix bugs:** Pick an open issue, fix it, and submit a pull request.
- **Improve documentation:** Fix typos, clarify instructions, or add examples to the README and other docs.
- **Suggest enhancements and ideas:** Open an issue to discuss new features or improvements before starting large changes.

## Getting Started

1. Fork this repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/<your-username>/github-final-project.git
   cd github-final-project
   ```
3. Create a new branch for your change:
   ```bash
   git checkout -b my-change
   ```
4. Make your changes and test them (for example, run `python simple_interest.py`).
5. Commit with a clear message:
   ```bash
   git commit -m "Describe your change"
   ```
6. Push to your fork and open a pull request:
   ```bash
   git push origin my-change
   ```

## Pull Request Guidelines

- Keep each pull request focused on a single change.
- Describe what you changed and why.
- Make sure the code runs without errors.
- Follow the existing code style.

## Reporting Issues

When opening an issue, please include:

- A clear, descriptive title
- Steps to reproduce the problem
- Expected and actual behavior
- Your Python version and operating system, if relevant

## Code of Conduct

Please be respectful and considerate to others. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the community standards.
